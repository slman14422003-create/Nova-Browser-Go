# يوتيوب في Nova Browser (WebView مخصّص ومنفصل)

أُزيلت واجهة يوتيوب الأصلية (YtScreen / YtApp / YtMini وجسر البيانات) كلياً. يوتيوب الآن يُعرض كما هو داخل **WebView مخصّص له فقط** منفصل عن بقية التطبيق.

## البنية (مجلد `yt/`)
- `YtWeb.kt` — إنشاء الـ WebView المخصّص وعميله (WebViewClient/WebChromeClient) ودورة حياته (خلفية، منبثقة، عودة، انهيار).
- `YtHub.kt` — حقن `assets/yt.js` مرة واحدة قبل سكربتات الصفحة + جسر الوسائط.
- `YtMedia.kt` — حالة التشغيل + سجل التشخيص (`YtLog`) + جسر `NovaYt`. `MediaService.kt` إشعار الوسائط.
- `YtDownload.kt` — تنزيل الفيديو/الصوت (NewPipeExtractor).

## ما الذي يجعله مستقراً؟
| المشكلة السابقة | الحل |
|---|---|
| تقطيع عند التنقل | لا `pwa.js` (كان يعدّل `history` وبيئة `matchMedia` ويحرّك `ytm-app`)، ولا `render.js` ولا `boost.js` ولا تشويش البصمة ولا اعتراض طلبات، ولا `SwipeRefreshLayout` (يعترض اللمس) |
| إعادة تحميل وفقدان الحالة بعد التصغير | لا مشغّل مصغّر ثانٍ ولا نقل WebView بين الحاويات. التبويب يحتفظ بنفس الـ WebView، و`discard` لا يمسّ تبويب يوتيوب أثناء التشغيل (`YtWeb.isLive`) |
| شاشة فارغة بعد النافذة المنبثقة | `YtWeb.recover`: إيقاظ المؤقتات + إعادة التخطيط/الرسم على 4 مراحل + إعادة ربط السطح + التراجع عن أنماط المنبثقة في الصفحة (آمن دائماً) |
| انهيار عملية العرض | يُعاد إنشاء الـ WebView بنفس الرابط، و«استئناف الفيديو» يعيدك لنفس اللحظة تقريباً |
| تعارض تسجيل الدخول | النطاقات المسموحة داخل الـ WebView: يوتيوب + `accounts.google.com` + صفحات الموافقة؛ وقبول كوكيز الطرف الثالث لهذا الـ WebView فقط |
| روابط خارجية في الوصف | تُفتح في **تبويب جديد** بلمسة المستخدم؛ لا تُمسّ صفحة يوتيوب |

## التبديل التلقائي
التبويب يستخدم الـ WebView المخصّص عندما يكون رابطه يوتيوب (`BrowserTab.yt`). عند كتابة رابط من النوع الآخر في نفس التبويب (`go()`) أو وصول تحويل من الخادم يبدّل `YtWeb.swapIfNeeded` الـ WebView ويحمّل الرابط.

## yt.js (ثلاثة أقسام)
- **FIX**: شكل/موضع الترجمة (من الإعدادات)، إخفاء لافتات «افتح التطبيق» وطبقة الاقتراحات عند الإيقاف، إعادة قياس الفيديو بعد الدوران، إخفاء Shorts (اختياري)، `__novaTop` للعودة للأعلى.
- **PLAY**: استئناف الفيديو، تذكّر السرعة، ضغط مطوّل ×2 (`ytResume` / `ytKeepRate` / `ytHold2x`).
- **MEDIA**: إشعار الوسائط، حماية التشغيل في الخلفية/المنبثقة، أوامر الإشعار. لمسة المستخدم على زر الإيقاف تُحترم دائماً (حتى داخل المنبثقة).
العلامات التي تستبدلها `YtHub`: `__CC__` `__UI__` `__PLAY__` `__BG__`.

## الإعدادات (الإعدادات ← يوتيوب)
متابعة التشغيل في الخلفية • نافذة منبثقة تلقائية • استئناف الفيديو • تذكّر السرعة • ضغط مطوّل ×2 • حجم/خلفية/موضع الترجمة • إخفاء Shorts • سجل التشخيص.

## ملفات السلاسة الموحّدة
- `perf/Smooth.kt` = `Perf` + `Adaptive` + `NovaMotion/pressScale` (كانت ثلاثة ملفات؛ الأسماء كما هي).
- `assets/smooth.js` = `render.js` + `boost.js` + التحميل الكسول (كانت سكربتين وسكربتاً ثالثاً في Kotlin). علامات: `__FIT__` `__LAZY__` `__BOOST__` `__POP__`.
- **تضارب أُزيل:** كان التحميل الكسول القديم يجعل *كل* الصور `lazy` بما فيها العلوية (فتأخّر ظهورها)، بينما `render.js` يؤجّل البعيد فقط. صارت سياسة واحدة: فك ترميز غير متزامن + تأجيل ما يبعد أكثر من شاشتين.
- `WebSupport` لم يعد يحقن شيئاً (بقي فيه تسخين DNS والتحديث الكامل ومراقبة الشبكة).
