# Nova Go

نسخة خفيفة من متصفح **Nova Browser** للأجهزة القديمة والضعيفة (أندرويد 6.0 فما فوق، وأجهزة Android Go). نفس المزايا تقريباً: تبويبات، حجب إعلانات وحماية خصوصية، مدير تنزيلات متعدد الاتصالات، وضع يوتيوب/PWA، كلمات مرور مشفّرة، مفضلة وسجل، عربي/English.

## ما تغيّر عن Nova Browser
- **minSdk 23** (أندرويد 6) بدل 29، ومعرّف مختلف `com.nova.browser.go` فيتعايش مع الأصلي.
- **جافا أقل:** هدف الشيفرة Java/JVM 1.8 (بدل 17) مع core library desugaring، ولا ملفات `.java` في المشروع (حُوّلت إلى Kotlin). CI يعمل بـ JDK 17 (أدنى ما يتطلبه AGP) بدل 25.
- **بلا مكتبات native:** حُذف FFmpeg فصار APK واحداً يعمل على armeabi-v7a وarm64 وx86 وبحجم أصغر بكثير.
- **توافق الأجهزة القديمة:** التخزين (ملف عادي + إذن على أندرويد 6–9، MediaStore من 10)، الإشعارات بلا قنوات قبل 8، FileProvider، قفل الشاشة بدل BiometricPrompt، تحقق تحديث بالتوقيعات القديمة، حماية من استدعاءات WebView غير الموجودة، `shouldOverrideUrlLoading` القديمة، وPiP/الحرارة/Safe Browsing تُفعَّل فقط حيث تُدعم.
- **الوضع الخفيف** (الإعدادات ← الأداء): يُكتشف تلقائياً (Android Go، رام قليلة، أندرويد ≤ 7.1، نواتان أو أقل) ويقصّر الحركات، يحدّ التبويبات الحيّة بـ 2، ويخفض اتصالات التنزيل؛ والحماية من البصمة والجلب المسبق معطّلان افتراضياً على هذه الأجهزة.
- **تصميم أبسط:** خط النظام بدل Serif، أيقونة وشاشة بداية ثابتتان قبل أندرويد 12، شريط تنقل أسود قبل أندرويد 8.

## حدود معروفة
- **لا تحويل صوت (MP3…)**: تُنزَّل ملفات يوتيوب الصوتية الأصلية M4A/WebM فقط.
- أندرويد 6 يعمل بـ WebView قديم؛ بعض المواقع الحديثة (ويوتيوب) قد لا تعمل كاملة. حدّث Android System WebView من المتجر.
- أندرويد 6/7.0 لا يحوي جذر Let's Encrypt الحديث: تظهر نافذة تسأل قبل المتابعة لكل موقع (قرار صريح، غير آمن).
- أندرويد 6/7: لا نافذة منبثقة (PiP) ولا مراقبة حرارة.
- لم يُبنَ المشروع ولم يُجرَّب على جهاز في بيئة التطوير هذه؛ أول بناء على GitHub Actions قد يكشف أخطاء ترجمة صغيرة.

## البناء
ارفع المشروع إلى GitHub وسيبني Actions ملف APK (Actions ← Artifacts). للتوقيع الثابت انظر `docs/SIGNING.md`. الوسم `v*` ينشئ إصداراً موقّعاً.
